4 LLM Prompt Construction

SYSTEM:
Tu es Dr. Amira, consœur numérique intégrée dans Dawini.
Tu réponds UNIQUEMENT à partir des RÉFÉRENCES fournies ci-dessous.
Si les références ne contiennent pas la réponse, dis :
"Je n'ai pas cette information dans mes références."
Ne devine pas. Ne complète pas de tes propres connaissances.
Cite toujours le document source.
Sois concise, professionnelle, et bienveillante.

CONTEXT (consultation screen — includes patient + vitals + motif):
Patient: Ahmed Benali, 52 ans, homme
Antécédents: Diabète type 2 (2019), HTA (2024)
Traitement en cours: Metformine 1000mg x2/j, Amlodipine 5mg/j
Dernière consultation: 12/02/2026 — TA 15/9, HbA1c 8.2%
Consultation en cours: TA 16/10, Poids 94kg, Motif: Céphalées

REFERENCES (from Layer 1 + Layer 2):

[L1 — Dorosz 2025, p.234]
"Amlodipine: doses 5-10mg/j en une prise. En cas de TA non
contrôlée sous 5mg, augmenter à 10mg avant d'ajouter un 2e AHT..."

[L1 — Guide HTA MSPRH, p.18]
"HTA grade 2 (TA 160-179/100-109): bithérapie recommandée.
Association IEC + ICa ou IEC + diurétique..."

[L2 — lab_normals]
TA normale adulte: < 140/90 mmHg
HbA1c cible diabétique: < 7%

QUESTION:
Que me suggères-tu pour ce patient avec TA 16/10 sous Amlodipine 5mg?

6 Streaming Response (SSE)

sequenceDiagram participant D as Doctor (Angular) participant API as AiController participant SVC as AiService participant RAG as RagService (L1) participant RULES as RulesService (L2) participant LLM as LlmService D->>API: POST /ai/query (SSE) API->>SVC: query(screen, question, context) par Search L1 and L2 in parallel SVC->>RAG: search(question) RAG-->>SVC: chunks from doctor's PDFs SVC->>RULES: lookup(keywords) RULES-->>SVC: structured data rows end SVC->>SVC: merge references SVC->>SVC: build prompt (system + context + refs + question) SVC->>LLM: generate(prompt, streaming=true) loop Token by token LLM-->>SVC: token SVC-->>API: SSE event API-->>D: SSE event (renders progressively) end LLM-->>SVC: [END] SVC-->>API: SSE close API-->>D: SSE close
Why SSE streaming? The LLM takes 3-5 seconds for a full response. With streaming, the doctor sees the first words in ~200ms. Feels instant, even though the full answer takes seconds.
