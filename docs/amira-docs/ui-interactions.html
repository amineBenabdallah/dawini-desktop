3 modes · context-aware · non-intrusive

Tiny, subtle, appears inside the form. Doctor sees it without looking away from their work.

Whisper Rules

  • Appears 500ms after the doctor finishes typing (debounced)
  • Font: 12px, muted color, subtle background tint
  • Dismissible with × (remembers per-session)
  • Never blocks input — always below the field
  • Maximum 1 whisper per field

Suggest Card Rules

  • Position: fixed bottom-right, above the FAB
  • Animation: slide in from right with spring bounce
  • Auto-dismiss after 15 seconds if not interacted with
  • Maximum 2 cards stacked at once
  • Red left-border for grave alerts, amber for moderate, blue for suggestions
  • Action buttons: primary action + ghost dismiss
  • Source badge at bottom — always show where the data came from

Talk Panel Rules

  • Trigger: FAB click or Ctrl+Space
  • Width: 380px, slides from right
  • Context bar: shows current patient + screen
  • Quick actions: pre-built buttons for common tasks
  • Streaming: tokens appear progressively (SSE)
  • Source badges: every response cites the document
  • Memory: conversation persists during the session, resets on patient change
  • Keyboard: Enter to send, Escape to close

FAB Behavior

  • Position: fixed, bottom-right, 20px from edges
  • Size: 48x48px, gradient blue → purple
  • Letter "A" for Amira (or custom SVG icon)
  • Hover: scale 1.05 + stronger shadow
  • Click: toggles Talk panel
  • Badge dot: appears when Amira has a pending suggestion
  • Pulse: when LLM is generating a response
  • Tooltip on hover: "Dr. Amira — Ctrl+Space"
  • Hidden on: login, setup, print routes
