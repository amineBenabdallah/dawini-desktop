Dawini Desktop

Votre cabinet médical, intelligent et hors ligne

Scénarios Happy Path — Guide de Découverte

Version 1.1 · Avril 2026 · Application de bureau

1. Installation 2. Configuration 3. Dr. Amira 4. Patients & RDV 5. Consultations 6. Facturation 7. Vérification

Comment utiliser ce guide

  • Cliquez sur chaque scénario pour le déplier / replier
  • Suivez les étapes dans l'ordre — chaque phase dépend de la précédente
  • Les Phases 1-3 sont à faire une seule fois (installation + configuration + IA)
  • Les Phases 4-7 couvrent le flux médical quotidien et la vérification finale
  • Chaque étape inclut un Résultat attendu pour valider le bon fonctionnement
  • Les identifiants sont des placeholders [email] à remplacer par vos vraies données
  • Aucun internet requis — tout fonctionne localement après installation

Phase 1

Installation & Premier lancement

Télécharger et installer Dawini Desktop, créer le cabinet via le formulaire de configuration initiale, se connecter et découvrir le dashboard. À faire une seule fois.

1 Installer Dawini Desktop Admin ~5 min ▶
1

Télécharger l'installateur

Récupérer le fichier d'installation Dawini-Desktop-Setup-1.0.exe depuis la source fournie (clé USB, lien partagé ou support technique).

✓ Le fichier d'installation est présent sur votre machine.
2

Lancer l'installation

Double-cliquer sur le fichier .exe. Suivre les étapes de l'installateur (accepter les termes, choisir le répertoire d'installation).

⚠ Windows Defender peut afficher un avertissement « Application non reconnue ». Cliquer sur Informations complémentaires → Exécuter quand même.
✓ L'installation se termine avec succès. Un raccourci Dawini Desktop apparaît sur le bureau.
3

Premier lancement de l'application

Double-cliquer sur le raccourci Dawini Desktop. L'application démarre et le serveur local embarqué s'initialise automatiquement.

✓ L'application s'ouvre et le formulaire de configuration initiale s'affiche automatiquement.
ℹ Au premier lancement, la base de données locale est créée automatiquement. Le modèle IA se charge en arrière-plan.
2 Configuration initiale — Créer mon cabinet Admin ~3 min ▶
Prérequis : L'application est lancée pour la première fois (Scénario 1). Le formulaire de configuration initiale est affiché.
1

Remplir le formulaire de création du cabinet

Le formulaire de configuration initiale affiche 4 champs. Remplir exactement :

Prénom[prénom] — placeholder : « Ali »
Nom[nom] — placeholder : « Benali »
Adresse e-mail[email_admin] — placeholder : « docteur@cabinet.dz »

✓ Le formulaire accepte toutes les données sans erreur de validation.
ℹ Il n'y a pas de champ « Confirmer le mot de passe ». Le mot de passe doit faire au minimum 8 caractères.
2

Soumettre le formulaire

Cliquer sur le bouton Créer mon cabinet.

✓ Le message « Cabinet créé ! Redirection... » s'affiche. L'application redirige automatiquement vers le tableau de bord.
⚠ Aucun email de confirmation n'est envoyé — tout se passe en local. Retenez bien vos identifiants.
3

Vérifier la page de connexion (optionnel)

Le lien « Déjà configuré ? Se connecter » en bas du formulaire mène à la page de connexion. Cette page permet de se reconnecter ultérieurement avec :

Adresse e-mail[email_admin]
Mot de passe[mot_de_passe] — avec bouton de visibilité (icône oeil)
✓ La page de connexion est accessible. Le bouton de visibilité du mot de passe fonctionne (icône œil).

ℹ Le dashboard se rafraîchit automatiquement toutes les 10 secondes. La sidebar de navigation donne accès à tous les modules : Patients, Rendez-vous, File d'attente, Consultations, Ordonnances, Certificats, Facturation, Employés, Paramètres.

Phase 3

Dr. Amira — Assistant IA médical

Indexer des documents médicaux dans la bibliothèque locale, tester le chat IA avec ses boutons d'action rapide, et observer le mode Whisper (indices inline lors de la saisie des signes vitaux).

7 Indexer des documents médicaux Docteur ~3 min ▶
Prérequis : Être connecté en tant qu'Admin ou Docteur. Avoir un fichier médical de référence (guide clinique, protocole, etc.).
1

Ajouter un document à la bibliothèque de Dr. Amira

Accéder à la section Dr. Amira → Bibliothèque. Cliquer sur Ajouter un document, sélectionner le fichier médical depuis votre ordinateur (PDF, guide clinique, protocole, etc.) et choisir sa catégorie (ex : « Guide clinique », « Protocole »). Cliquer sur Indexer.

✓ Dr. Amira analyse et enregistre automatiquement le contenu du document dans sa mémoire locale. Elle pourra désormais référencer ce document dans ses réponses.
2

Vérifier la bibliothèque

La bibliothèque affiche la liste des documents intégrés avec le nombre de passages analysés par Dr. Amira pour chaque document.

✓ Le document apparaît dans la bibliothèque, confirmant que l'intégration a réussi.
ℹ Vous pouvez supprimer un document de la bibliothèque en cliquant sur l'icône de suppression à côté du document concerné.
8 Tester le panneau Chat de Dr. Amira Docteur ~3 min ▶
Prérequis : Un document a été indexé (Scénario 7). Le modèle IA est chargé (vérifier dans Paramètres → onglet Amira : « Modèle chargé » en vert).
1

Ouvrir le panneau Chat

Cliquer sur l'icône Dr. Amira (bouton flottant). Le panneau de chat glisse depuis la droite.

Barre de contexteEn haut du panneau, indique l'écran actuel pour contextualiser les réponses
Boutons d'action rapideDiagnostic · Ordonnance · Certificat · Résumé
Champ de saisieEn bas du panneau, avec un bouton Envoyer
✓ Le panneau s'ouvre en glissant depuis la droite. La barre de contexte, les boutons d'action rapide et le champ de saisie sont visibles.
2

Poser une question médicale

Taper une question dans le champ de saisie, par exemple :

Question test« Quel est le traitement de première intention pour une hypertension artérielle de grade 1 ? »

Cliquer sur le bouton Envoyer (ou appuyer sur Entrée).

✓ La réponse s'affiche dans le panneau. Les messages du docteur apparaissent en bleu à droite, ceux d'Amira en blanc à gauche avec des badges de source indiquant les documents référencés.
3

Tester les boutons d'action rapide

Cliquer sur l'un des boutons d'action rapide (« Diagnostic », « Ordonnance », « Certificat » ou « Résumé ») pour déclencher une requête contextuelle à Dr. Amira.

✓ Dr. Amira répond avec un contenu adapté au type d'action demandé et au contexte de l'écran en cours.
9 Observer le mode Whisper et le contrôle des vitaux Docteur ~2 min ▶
Prérequis : Ce scénario sera pleinement testé lors de la Phase 5 (consultation). Pour l'instant, il suffit de comprendre le concept.
1

Comprendre le contrôle des vitaux

Lors de la saisie des signes vitaux dans une consultation, Dr. Amira effectue automatiquement un contrôle des valeurs saisies. Si une valeur sort des normes, une alerte s'affiche directement à côté du champ concerné :

Tension artérielleEx : « 18/11 » → alerte « HTA Grade 2 »
PoidsEx : 85 kg → aucune alerte si dans les normes
TempératureEx : 39.5°C → alerte « Fièvre élevée »
✓ Le concept est compris. Le contrôle des vitaux sera vérifié en direct lors du Scénario 15 (consultation).
2

Comprendre le mode Whisper

Le mode Whisper est automatique : lorsque le docteur saisit les signes vitaux dans le formulaire de consultation, des indices inline apparaissent directement à côté des champs.

Exemple — Tension 18/11Un indice inline « HTA Grade 2 » apparaît à côté du champ
Exemple — Température 39.5°CUn indice inline « Fièvre élevée » apparaît avec une suggestion
✓ Le mode Whisper sera visible concrètement dans le formulaire de consultation (Scénario 15).

Phase 6

Facturation — Factures & Paiements

Créer des factures liées aux consultations, enregistrer des paiements (6 modes) et suivre le statut automatique (Impayée → Partielle → Réglée).

19 Créer une facture Secrétaire ~2 min ▶
Prérequis : La consultation d'Amina Benali est finalisée (Scénario 15).
1

Créer une facture

Aller dans Facturation → Cliquer sur + Nouvelle facture. Remplir le formulaire :

ConsultationConsultation d'Amina Benali (rempli automatiquement)
PatientAmina Benali (rempli automatiquement)
Montant total2000 DA
MédecinRempli automatiquement
NotesConsultation générale (optionnel)

Cliquer sur Créer la facture.

✓ La facture est créée avec le statut Impayée.
20 Enregistrer un paiement Secrétaire ~2 min ▶
Prérequis : La facture a été créée (Scénario 19) avec le statut Impayée.
1

Ajouter un paiement

Ouvrir la facture → Cliquer sur Ajouter un paiement. Remplir le formulaire :

Montant2000 DA
MéthodeDropdown : ESPECES / CHEQUE / VIREMENT / EDAHABIA / BARIDIMOB / CIB — sélectionner ESPECES
Date de paiementAujourd'hui
NotePaiement complet en espèces (optionnel)

Cliquer sur Enregistrer le paiement.

✓ Le statut de la facture passe automatiquement à Réglée (le montant payé égale le montant total). Le paiement apparaît dans la liste des paiements de la fenêtre de détail.
2

Imprimer la facture

Cliquer sur Imprimer.

✓ La facture s'affiche en format imprimable avec : en-tête du cabinet, détails patient, montant, mode de paiement et statut « Réglée ».
ℹ Vous pouvez tester un paiement partiel : enregistrer 1000 DA sur 2000 DA → le statut passe automatiquement à Paiement partiel, puis ajouter les 1000 DA restants → Réglée. Le statut est calculé automatiquement : Impayée (0 DA payé) → Paiement partiel (montant partiel) → Réglée (montant total atteint).
