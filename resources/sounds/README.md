# Audio Files

Place these audio files here before building:

- `soft-click.mp3` — Subtle UI click feedback (~0.1s, low volume)
- `chime.mp3` — Queue notification chime (~1s, pleasant bell tone)

## Free sources:
- https://freesound.org (search "soft click", "notification chime")
- https://mixkit.co/free-sound-effects/

Keep files small (<50KB each) for fast playback.
